# MGM DABHA - Authentic South Indian & Multi-Cuisine Family Restaurant

**MGM DABHA** is a complete, enterprise-grade restaurant management web application built for Dharmapuri, Tamil Nadu. It provides an online food ordering experience similar to Zomato/Swiggy along with 5 dedicated role portals (Customer, Admin, Owner, Kitchen KDS, and Delivery).
